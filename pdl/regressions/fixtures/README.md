# Hardened-baseline diagnostic fixtures

These are public Showdown protocol captures from the current Adam-versus-Steve 3×3 diagnostic batch. They preserve observed pathology positions for later evaluator and search work. They contain no submitted team files, private requests, hidden-set audit, or target actions.

The metadata records the small diagnostic budget used to discover each sequence. Future regression work should replay or reconstruct the position at the stated turn under several budgets and assess progress rather than asserting a hardcoded move.
