# Adam vs Steve team-strategy study

This is the validated fixed six-team scenario for the local PDL runtime:

```text
local Showdown → Foul Play posterior → weighted correlated set sampler → poke-engine Rust MCTS → deterministic argmax
```

`scenario.json` defines the three Adam and three Steve builds. `belief.json` is the local prior. `TEAM_CORRECTIONS.json` records the live-roster and rules corrections. `VALIDATION.json` is regenerated by the validation command.

Run from the simulator root. Every command validates the scenario, runs the fixed matrix at 250 ms per belief world with `belief-samples=1`, then writes the analysis CSVs and report.

```bash
STAMP=$(date +%Y%m%d-%H%M%S); RUN="calculations/adam-vs-steve-team-strategy-screening-$STAMP"; npm run pdl:validate-team-strategy -- --scenario pdl/studies/adam-vs-steve-team-strategy/scenario.json --output pdl/studies/adam-vs-steve-team-strategy/VALIDATION.json && npm run pdl:simulate-fixed -- --scenario pdl/studies/adam-vs-steve-team-strategy/scenario.json --repetitions 20 --decision-budget-ms 250 --belief-samples 1 --timeout-ms 900000 --foul-root '/Users/amanery/PDL Vercel App/pdl-s4-foul-play' --output "$RUN" --belief-engine posterior && npm run pdl:analyze-team-strategy -- --input "$RUN" --scenario pdl/studies/adam-vs-steve-team-strategy/scenario.json
```

Use `--repetitions 50` for the 450-game standard study and `--repetitions 100` for the 900-game deep study. Each repetition count is even, so every matchup cell is balanced between p1 and p2.

The report treats only clean terminal forward/reverse pairs as aggregate-ready. It reports empirical Monte Carlo rates with Wilson intervals; it does not label search values as match probabilities.
